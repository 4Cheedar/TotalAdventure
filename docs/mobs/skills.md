<h2 id="conceito">✨ Skills de Mobs</h2>

<p>
Skills transformam mobs em <strong>ameaças ativas</strong>.
</p>

<p>
Elas quebram padrões,<br>
punem repetição<br>
e forçam o jogador a reagir,<br>
não apenas calcular dano.
</p>

<div class="lore-quote">
Se um mob tem skill,<br>
ele não luta sozinho.<br>
Ele executa um plano.
</div>

<div class="ritual-divider">🧠</div>

<h2 id="o-que-sao">🧠 O que são skills</h2>

<p>
Skills são <strong>habilidades configuráveis</strong>
que mobs podem usar durante o combate.
</p>

<p>
Elas podem:
</p>

<ul>
  <li>causar dano</li>
  <li>aplicar efeitos</li>
  <li>alterar comportamento</li>
  <li>executar comandos</li>
  <li>reagir a eventos específicos</li>
</ul>

<div class="lore-quote">
Uma skill não é bônus.<br>
É <strong>decisão automática do inimigo</strong>.
</div>

<div class="ritual-divider">⚙️</div>

<h2 id="funcionamento">⚙️ Como skills funcionam</h2>

<p>
Cada skill define:
</p>

<ul>
  <li><strong>quando</strong> é ativada (trigger)</li>
  <li><strong>como</strong> é executada (type)</li>
  <li><strong>com que frequência</strong> (cooldown)</li>
  <li><strong>com qual chance</strong> (chance)</li>
  <li><strong>em quem</strong> (target)</li>
  <li><strong>com quais parâmetros</strong> (parameters)</li>
</ul>

<p>
Isso permite criar:
</p>

<ul>
  <li>mobs previsíveis</li>
  <li>mobs caóticos</li>
  <li>mobs punitivos</li>
  <li>mobs estratégicos</li>
</ul>

<div class="ritual-divider">⏱️</div>

<h2 id="triggers">⏱️ Triggers (gatilhos)</h2>

<p>
Triggers definem <strong>o momento da ativação</strong>.
</p>

<p>
Triggers comuns:
</p>

<ul>
  <li><strong>ON_SPAWN</strong> → ao nascer</li>
  <li><strong>ON_ATTACK</strong> → ao atacar</li>
  <li><strong>ON_DAMAGE</strong> → ao receber dano</li>
  <li><strong>ON_DEATH</strong> → ao morrer</li>
  <li><strong>ON_TICK</strong> → verificação periódica</li>
</ul>

<div class="lore-quote">
O combate não é linear.<br>
Eventos importam.
</div>

<div class="ritual-divider">🧩</div>

<h2 id="tipos">🧩 Tipos de skill</h2>

<h3>🧪 potion</h3>
<ul>
  <li>aplica efeitos de poção</li>
  <li>buffs ou debuffs</li>
  <li>controle indireto</li>
</ul>

<h3>💥 damage</h3>
<ul>
  <li>causa dano direto</li>
  <li>ignora ou respeita defesa</li>
  <li>pode escalar com level</li>
</ul>

<h3>📜 command</h3>
<ul>
  <li>executa comandos</li>
  <li>permite integração com outros sistemas</li>
  <li>cria efeitos globais</li>
</ul>

<h3>🤖 behavior</h3>
<ul>
  <li>lógica personalizada</li>
  <li>movimentos especiais</li>
  <li>saltos, investidas, padrões únicos</li>
</ul>

<div class="lore-quote">
Behavior é onde surgem<br>
os mobs realmente perigosos.
</div>

<div class="ritual-divider">🎯</div>

<h2 id="chance">🎯 Chance e cooldown</h2>

<p>
Skills podem ter:
</p>

<ul>
  <li><strong>chance de ativação</strong></li>
  <li>fixa ou baseada em expressões</li>
  <li><strong>cooldown</strong></li>
  <li>impede spam</li>
  <li>cria janelas de oportunidade</li>
</ul>

<div class="lore-quote">
O jogador aprende a<br>
<strong>esperar o erro do mob</strong>.
</div>

<div class="ritual-divider">📈</div>

<h2 id="escalonamento">📈 Skills que escalam</h2>

<p>
Muitas skills usam o <strong>level do mob</strong>.
</p>

<p>
Isso permite:
</p>

<ul>
  <li>mesma skill em vários estágios</li>
  <li>progressão natural de dificuldade</li>
  <li>reaproveitamento inteligente</li>
</ul>

<div class="lore-quote">
Uma skill simples no level 5<br>
vira ameaça real no level 30.
</div>

<div class="ritual-divider">🎯</div>

<h2 id="alvos">🎯 Alvos (target)</h2>

<p>
Skills podem escolher alvos diferentes:
</p>

<ul>
  <li>o próprio mob</li>
  <li>jogador mais próximo</li>
  <li>todos em um raio</li>
  <li>quem causou o último dano</li>
</ul>

<div class="lore-quote">
Target errado = skill inútil.<br>
Target certo = caos.
</div>

<div class="ritual-divider">🔁</div>

<h2 id="passivas">🔁 Skills passivas e ativas</h2>

<h3>🔁 Passivas</h3>
<ul>
  <li>sempre ativas</li>
  <li>efeitos contínuos</li>
  <li>auras, resistências, reflexos</li>
</ul>

<p>
Punem aproximação descuidada.
</p>

<h3>⚡ Ativas</h3>
<ul>
  <li>ativadas por trigger</li>
  <li>têm cooldown</li>
  <li>geram picos de perigo</li>
</ul>

<p>
Criam momentos de tensão.
</p>

<div class="ritual-divider">⚠️</div>

<h2 id="impacto">⚠️ O que isso significa para o jogador</h2>

<ul>
  <li>observar animações importa</li>
  <li>repetir padrão é perigoso</li>
  <li>distância nem sempre é segura</li>
  <li>agressividade pode ser punida</li>
  <li>recuar faz parte da luta</li>
</ul>

<div class="lore-quote">
Se um mob “do nada” te matou,<br>
provavelmente ele <strong>não fez isso do nada</strong>.
</div>

<div class="ritual-divider">🧠</div>

<h2 id="filosofia">🧠 Filosofia das skills</h2>

<ul>
  <li>mobs reagem</li>
  <li>combate é dinâmico</li>
  <li>dificuldade é legível</li>
  <li>erro ensina</li>
</ul>

<div class="lore-quote">
Skills existem para quebrar o piloto automático.<br>
Quem aprende a ler mobs,<br>
para de morrer para eles.
</div>
